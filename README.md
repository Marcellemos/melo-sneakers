# Melo Sneakers

Uma landing page estática em HTML, CSS e JavaScript para uma loja de tênis chamada **MELO SNEAKERS**.

## Visão geral

- Página de apresentação com hero em vídeo e overlay.
- Navegação responsiva com links de categorias e ícones de pesquisa/carrinho.
- Cards de produtos com imagens, descrição e botão de adicionar ao carrinho.
- Footer com links de loja, suporte e redes sociais.

## Arquivos principais

- `index.html` - estrutura da página.
- `style.css` - estilos e layout.
- `script.js` - interatividade e lógica do carrinho.
- `img/` - imagens e vídeos usados na página.

## Como usar

1. Abra `index.html` no navegador.
2. Navegue pela página e use os botões para explorar o layout.

## Customização

- Atualize o conteúdo dos cards no `index.html` para trocar produtos e preços.
- Ajuste o visual em `style.css` para cores, tipografia e responsividade.
- Modifique o comportamento de interação em `script.js` para adicionar novos recursos.

## Observações

- Projeto está em Português brasileiro (`pt-br`).
- Feito como porta-fólio ou demonstração de design de produto.
